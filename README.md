# AI-Based Ransomware Detection System

## Overview
This project uses Machine Learning to detect ransomware and malicious behavior using process-related system features.

## Features
- Malware prediction
- Streamlit dashboard
- CSV upload support
- Visualization charts
- Download prediction results

## Technologies Used
- Python
- Scikit-learn
- Pandas
- Streamlit
- Plotly

## ML Algorithm
- Random Forest Classifier

## Accuracy
- 100% Accuracy on test dataset

## Run Project

```bash
streamlit run app/app.py
